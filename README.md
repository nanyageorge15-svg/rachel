# Recheal Enterprises Website
A responsive business/enterprise website concept built with HTML5, CSS3, and JavaScript.

## Pages / sections
- Home hero
- About
- Services
- Shop showcase
- Contact enquiry form

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
The enquiry form is a front-end demo and does not send messages to an email inbox or database. Replace sample copy, imagery, services, and business contact details with approved client information before publishing.
